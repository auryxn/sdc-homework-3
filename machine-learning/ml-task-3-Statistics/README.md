# Домашнее задание 1 — Статистика

Откройте `Topic03_Statistics_solved.ipynb` в Jupyter Notebook, JupyterLab или Google Colab и выполните ячейки сверху вниз.

В первой части задания данные создаются прямо в ноутбуке. Для второй части нужен файл `StudentsPerformance.csv` из датасета Kaggle Students Performance in Exams. Поместите CSV в эту же папку перед запуском.

В ноутбуке заполнены вычисления описательной статистики, симуляция центральной предельной теоремы, односторонний t-тест для сравнения групп A/B, доверительный интервал, а также анализ реального датасета с Welch t-test, однофакторной ANOVA и χ²-тестом.
