# Домашнее задание 2 — Регрессия

Откройте `Topic04_Regression_solved.ipynb` в Jupyter Notebook, JupyterLab или Google Colab и выполните ячейки сверху вниз.

Для части 1 используются синтетические данные, которые генерируются в ноутбуке. Для части 2 требуется `housing.csv` из датасета California Housing Prices на Kaggle. Поместите CSV в эту же папку перед запуском.

В ноутбуке заполнены простая и множественная регрессии, метрики RMSE/MAE/R², график остатков, preprocessing pipeline с масштабированием и one-hot encoding, сравнение с бейзлайном и ранжирование коэффициентов.
